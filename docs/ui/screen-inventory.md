## Responsive Transformation Rules

- **Desktop (>= 1280px):** Permanent 250px left sidebar, wide multi-column layout, dense data tables with full columns visible.
- **Laptop / Tablet (768px – 1279px):** Collapsible sidebar, horizontal scroll on data tables with sticky leftmost ID/Name columns, 2-column card layouts.
- **Mobile (< 768px):** Off-canvas mobile navigation drawer, single-column stacked cards, full-width touch targets (minimum 44x44px), contextual bottom sheets for quick actions.
